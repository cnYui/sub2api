# 购买页产品卡片浅色模式设计

## 背景

用户在 `aaccx.pw/purchase` 浅色模式下看到订阅套餐和 GPT 流量卡仍是黑底白字，希望这些卡片在浅色模式下切换为白底黑字。截图中的卡片由前端共享组件 `frontend/src/components/payment/PurchaseProductCard.vue` 渲染，订阅套餐、GPT 流量卡和续费选择弹窗复用同一组件。

当前组件样式使用固定 `bg-black`、`text-white`、`border-white/*`、黑色阴影和白色按钮，因此不响应项目已有的 Tailwind `darkMode: 'class'` 主题机制。

## 已确认边界

- 只修改 `PurchaseProductCard.vue` 的视觉主题样式。
- 覆盖 `/purchase` 产品列表中的订阅套餐和 GPT 流量卡。
- 覆盖同页续费选择弹窗里复用的同款产品卡片。
- 不修改购买确认页、支付方式选择、订单状态、侧边栏、顶部栏和后端支付/订阅逻辑。
- 不新增业务字段，不改变产品排序、价格、套餐文案或点击行为。
- 深色模式继续保留当前黑卡白字的高对比效果。

## 视觉方案

采用用户确认的方案 B：轻高级白卡。

浅色模式：

- 卡片背景为白色到极浅灰的轻微纵向渐变。
- 边框使用浅灰，顶部边框略强调，保留产品卡层次。
- 阴影比普通 `.card` 更明显，但低于当前黑卡的强阴影。
- 主标题、价格、明细值使用黑色或近黑色。
- `PLAN`、`Price`、明细标签使用中性灰。
- 分隔线使用浅灰。
- 主按钮为黑底白字圆角胶囊按钮，hover 可轻微反转为白底黑字或降低黑色强调。

深色模式：

- 保留当前黑底、白字、白色按钮和深色阴影观感。
- 仅通过 `dark:` 类名显式恢复现有颜色，避免浅色样式污染深色模式。

## 实现方式

- 将 `PurchaseProductCard.vue` 中固定的黑卡 Tailwind 类改为浅色默认 + `dark:` 覆盖。
- 保持现有 DOM 结构、props、emit 和 `data-testid` 不变。
- 保持 `min-h-[380px]`、圆角、内部间距、标题字号、价格字号和列表布局不变，降低视觉改动风险。
- 使用 Tailwind 原子类完成，不新增全局 CSS，不引入新主题变量。

## 测试策略

- 更新 `frontend/src/components/payment/__tests__/PurchaseProductCard.spec.ts`。
- 断言卡片默认具备浅色模式类，例如白/浅灰背景、浅灰边框、深色文字或按钮。
- 断言仍存在 `dark:` 黑卡样式，保证深色模式不会退化。
- 保留现有内容渲染与点击事件断言，确保订阅和流量卡行为不变。

## 风险与取舍

- 由于组件被续费弹窗复用，弹窗里的产品卡片也会变成浅色白卡；这属于已确认范围。
- 不改全局 `.card`，避免影响后台、确认页和其他普通信息卡。
- 不引入 CSS 变量，当前改动范围较小，直接使用 Tailwind 类最符合现有代码风格。
- 视觉 companion 生成的 `.superpowers/` 目录当前未被 `.gitignore` 忽略，属于本次设计沟通临时文件，不应纳入功能提交。

## 自检

- 无占位内容。
- 范围只包含购买页共享产品卡片样式。
- 深色模式保留和浅色模式切换没有冲突。
- 测试覆盖视觉类名、内容渲染和点击行为。
