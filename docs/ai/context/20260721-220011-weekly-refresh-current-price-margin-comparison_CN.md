# 2026-07-21 当前价格不变的周刷新额度与毛利对比

## 目标

用户希望当前价格基本不变，将订阅周期改为：

```text
28 天周期 = 4 个 7 天额度窗口
```

并对比当前价格下，`30% / 25% / 20%` 毛利分别能给多少等价日额度和每周刷新额度。

## 成本假设

```text
1 个 Plus 账号 = 150 USD/天
采购成本 = 12 RMB/天
成本单价 = 12 / 150 = 0.08 RMB/USD
```

## 公式

```text
28 天总额度 = 月价RMB * (1 - 目标毛利率) / 0.08
等价日额度 = 28 天总额度 / 28
每周刷新额度 = 28 天总额度 / 4
```

也就是：

```text
等价日额度 = 月价RMB * (1 - 目标毛利率) / 2.24
```

## 初步建议

- 如果当前价格基本不变，30% 毛利仍然更稳；20% 毛利对高强度用户更友好，但利润缓冲很薄。
- 产品上建议只展示“每周刷新额度”，不要继续强调“日额度”，避免用户误解为每天刷新。
- 后端应从 `daily_limit_usd` 迁移到权益周期窗口额度，或者新增 `quota_window_days=7` 与 `window_limit_usd`，避免继续用 daily 字段表达周额度。
