# 用户侧渠道入口与价格展示设计

## 背景

用户希望先不在普通用户页面展示 `/monitor` 渠道状态入口，同时在 `/available-channels` 页面明确展示当前可用的 `gpt-5.4`、`gpt-5.5` 以及生图价格。

## 目标

- 普通用户侧边栏不再出现「渠道状态」入口。
- `/monitor` 路由、用户只读接口、管理员 `/admin/channels/monitor` 配置页暂时保留，避免破坏已有监控能力。
- `/available-channels` 页面在表格前增加价格摘要，展示当前接口返回中用户可见的 `gpt-5.4`、`gpt-5.5` 和图片生成模型价格。

## 方案

采用最小改动：

1. 从用户侧导航声明中移除 `{ path: '/monitor' }` 项，不改 feature flag、不改路由守卫。
2. 在 `AvailableChannelsView.vue` 中从 `channels` 响应数据派生价格摘要。
3. 摘要只读取当前用户可见数据：如果用户无权限看到某模型或后端未配置价格，则显示未配置，不硬编码后台价格。
4. GPT 文本模型展示输入、输出、缓存写入、缓存读取的每百万 token 单价。
5. 生图展示按图片计费模型的单张价格；如果同名模型存在多个尺寸阶梯，则保留阶梯标签。

## 取舍

- 不删除 `/monitor` 路由：便于之后恢复入口，也不影响管理员配置和后端监控调度。
- 不新增后端接口：`/channels/available` 已经返回用户可见模型和定价，前端直接汇总即可。
- 不用静态营销文案写死价格：避免后台价格调整后页面和真实计费不一致。

## 验证

- 新增侧边栏源码测试，断言用户侧导航不再声明 `/monitor`。
- 新增可用渠道页组件测试，模拟接口数据后断言价格摘要包含 `gpt-5.4`、`gpt-5.5`、生图模型和 `$0.10 / 张` 等价格。
- 运行相关 Vitest、前端 typecheck/build。
