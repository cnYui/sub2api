用户提醒：部分订阅不是纯旧额度残留，可能在 2026-07-06 今天已经产生真实用量，不能直接把 `daily_usage_usd` 清零。

因此本次处理规则调整为：

- `daily_window_start < 2026-07-06 00:00:00+08`
- 且 active 订阅、未删除、未过期、分组有日额度
- 如果 2026-07-06 00:00:00+08 之后没有成功用量：`daily_usage_usd=0`
- 如果今天已有成功用量：`daily_usage_usd=今天 usage_logs.total_cost 聚合值`
- 所有被处理订阅统一把 `daily_window_start` 置为 `2026-07-06 00:00:00+08`
- 不修改 `weekly_usage_usd`、`monthly_usage_usd`、套餐状态、到期时间、分组绑定、流量卡余额
