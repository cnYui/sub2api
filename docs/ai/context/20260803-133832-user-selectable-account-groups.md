# 用户可选账号分组配置

时间：2026-08-03 13:38:32（Asia/Tokyo）

## 背景

当前部署 `sub2api-official-18082` 有 7 个启用且可调度的 OpenAI API Key 账号，但没有活跃分组，也没有账号到分组的关联。已有 `default` 与 `free803` 分组均已软删除，用户创建 API Key 时的可选分组列表为空。

## 决策

为每个活跃账号创建一个同名的标准、公开、启用 OpenAI 分组，并一对一绑定对应账号。将这 7 个分组关联到现有渠道“GPT模型官方0.15倍价格”，使渠道层的模型定价继续适用于用户选中的任一分组。

不恢复软删除的旧分组：删除流程已经移除了相关账号和用户授权关系，直接恢复 `deleted_at` 会留下不完整配置。

## 验证条件

1. 有 7 个新的启用、非专属、标准 OpenAI 分组。
2. 每个分组仅绑定其对应账号，7 个账号均有且仅有一个分组绑定。
3. 现有渠道关联这 7 个分组。
4. 普通用户请求 `/api/v1/groups/available` 时可得到这 7 个分组。
