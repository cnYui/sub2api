# 七个渠道监控模型别名复核

## 方法

对七个账号分别实时读取上游 `/v1/models`，再与每条渠道监控的主模型和附加模型比对：

- 检查是否存在相同模型的大小写重复。
- 检查主模型是否被重复配置为附加模型。
- 确认保留模型均仍出现在对应上游实时列表中。

## 结果

- Grok：8 个模型均为不同能力或版本。
- Claude Max：9 个模型均为不同版本。
- Claude Kiro：11 个模型均为不同版本；带日期的 Opus 版本不是别名。
- GLM：`glm-5.1` 与 `glm-5.2` 为不同版本。
- Kimi：`kimi-k2.5`、`kimi-k2.6`、`kimi-k3` 为不同版本。
- GPT：`gpt-5.5`、不同的 `gpt-5.6-*` 变体、Codex 和图像模型均为上游独立模型。
- DeepSeek：上游同时返回大小写别名 `DeepSeek-V4-Flash` 和拼写别名 `deepseep-v4-flash`；已删除，仅保留 `deepseek-v4-flash`。

## 验证

对当前七条监控的主模型和附加模型按不区分大小写分组后，没有任何重复条目。
