# ZPay 退款金额逻辑精简

## 决策

按用户确认，退款金额必须始终以退款页面计算结果为准，不维护独立的“完整退款”分支。

通用支付服务商继续使用统一比例公式：`实付金额 × 页面退款金额 ÷ 订单标价`。当页面退款金额恰好等于订单标价时，公式自然得到原实付金额，因此不需要额外判断。

ZPay 使用页面退款金额直接调用退款 API，不再区分部分或完整退款：订单 `536` 的下一次请求参数为 `money=1.99`。

## 实现

- `NetPartialRefundAmountProvider` 重命名为 `RefundQuoteAmountProvider`，语义改为“网关直接使用退款报价”。
- 删除 ZPay 对“是否完整退款”的比较分支。
- 删除 `calculateGatewayRefundAmount` 对等额退款的特判，统一保留比例计算。
- 原有退款成功后的余额套餐撤销与失败审计幂等性改动保持不变。
