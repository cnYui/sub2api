# 首页 GPT-5.6 与价格清单实施计划

> **给执行代理：** 按任务顺序执行，每一步完成后运行对应验证。

**目标：** 默认首页下架 5.3 系列展示，改为 GPT-5.6，并静态列出当前购买页的全部套餐和流量卡价格。

**架构：** 仅修改首页展示层。`HomeView.vue` 内维护只包含公开展示字段的静态模型与商品数据，模板用 `v-for` 渲染，价格卡复用首页认证跳转目标；不触及受 JWT 保护的购买接口。

**技术栈：** Vue 3、TypeScript、Vitest、Vue Test Utils、Tailwind CSS。
