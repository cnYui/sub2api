### 模型白名单

上游 `GET /v1/models` 实际返回 23 个模型。白名单按项目既有口径配置为 **20 个文本模型**，
排除 `gpt-image-1`、`gpt-image-1.5`、`gpt-image-2`。

排除理由：`Image-2生图` 分组为 `1x`，若允许图像模型走本 `0.28x` 分组，
生图请求会以约 1/3.5 的价格绕过独立生图渠道——与 2026-08-04 建立 GPT 0.1 低价渠道时的处置一致。

创建表单的默认 20 项预置列表与该上游并不匹配，已做如下修正：

- 移除上游不存在的 `gpt-5.6-luna`、`gpt-5.4-mini`
- 补入上游存在但预置列表缺失的 `gpt-5.3-codex`、`gpt-5.2-openai-compact`、
  `gpt-5.3-codex-openai-compact`、`gpt-5.4-openai-compact`、`gpt-5.5-openai-compact`
  （其中 `gpt-5.3-codex` 为 Codex 主力模型，缺失会直接导致该模型被拒）

账号编辑页的「同步最新支持模型」按钮在创建态和编辑态均未发出任何网络请求，

## 验证

新建验证用 API Key `gpt028-verify`（key ID `387`，`group_id=74`）后实测：

1. `GET https://api.aaccx.pw/v1/models` 返回 **20 个模型**，与白名单完全一致，图像模型已不可见。
2. `POST https://api.aaccx.pw/v1/chat/completions`，模型 `gpt-5.6-terra`，HTTP `200`，
   返回内容为预期的 `G028_OK`，`finish_reason=stop`，
   用量 `prompt 8346 / completion 14 / cached 7488`。
3. 后台使用记录该笔请求：标准成本 `$0.003382`，实际扣费 `$0.017043`。
   校验 `0.003382 × 0.28 × 18 = 0.017045`，与隐藏最终倍率 `18x` 的既有公式一致。
4. `gpt-5.6-sol` 同样返回 HTTP `200`。
5. `gpt-5.3-codex` 经网关返回 `502`；直连上游 `${OPS_UPSTREAM_GPT028_HOST}` 复现为
   HTTP `429`「All available accounts are currently rate-limited」，
   属上游账号池对该模型限流，与本地分组、白名单和账号配置无关。
