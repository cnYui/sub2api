## 结论

### 网络出入站流量

当前 PostgreSQL **没有保存请求体字节数、响应体字节数、Nginx `bytes_sent`、Cloudflare 带宽或上下行带宽字段**，因此不能从数据库准确计算 MB/GB 级的网站网络出入站流量。

全库与大小相关的业务字段只有图片规格和用户头像 `byte_size`，不代表 API 网络流量。

## 数据完整性说明

- `usage_logs` 覆盖 2026-06-18 07:22 至快照时间。
- `usage_dashboard_hourly` 持续更新到当前小时，聚合水位与原始表仅有秒级写入差异。
- `ops_metrics_hourly` 只更新到 2026-06-26，不能用于判断当前失败请求峰值。
- 若要准确回答网站 GB/MB 出入站流量，应接入 Cloudflare Analytics，或让 Nginx 结构化记录并汇总 `request_length`、`bytes_sent`；数据库现状无法倒推出历史真实字节流量。
