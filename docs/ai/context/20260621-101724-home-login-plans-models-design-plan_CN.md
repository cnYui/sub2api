# 首页登录入口、套餐与模型展示修正计划

## 背景

用户在本地 `http://localhost:5174/home` 预览最新前端时发现首页默认内容仍存在三处错误：

- 未登录态页面同时存在 Hero 区 CTA 和右上角登录按钮，登录入口重复。
- Hero CTA 文案仍是「立即开始」，应直接表达为「立即登录」。
- 中部三张卡片仍描述功能能力，不符合当前售卖套餐。
- 底部支持模型仍展示 Claude、GPT、Gemini、Antigravity 等旧内容。

## 修改边界

- 只修改前端首页默认内容和相关前端测试。
- 不修改后端、API、鉴权、计费、数据库、路由守卫或公网配置。
- 保持现有首页版式、黑白灰视觉、卡片数量和按钮样式不变。
- 已登录态右上角控制台入口保留，避免用户登录后缺少快速进入控制台的入口。

## 设计

- 未登录态：移除右上角匿名态登录按钮，只保留 Hero 区主 CTA；CTA 文案改为「立即登录」，仍跳转 `/login`。
- 已登录态：Hero CTA 仍显示「进入控制台」，右上角仍显示控制台入口。
- 三张中部卡片改为套餐：
  - 29 元套餐：额度 19 刀。
  - 39 元套餐：额度 29 刀。
  - 59 元套餐：额度 49 刀。
- 三个套餐说明均包含「每天 24 点自动刷新，可使用 30 天」。
- 在页面套餐说明中加入「使用 cc-switch 项目，一键接入 API 到 Codex」。
- 支持模型只展示：
  - GPT 5.3
  - Codex 5.4
  - GPT 5.5

## 验证计划

- 新增首页组件测试，先确认当前实现失败：
  - 未登录态只存在一个 `/login` 链接。
  - 页面包含「立即登录」，不包含「立即开始」。
  - 页面包含三档套餐、刷新周期和 cc-switch/Codex 文案。
  - 页面只展示 GPT 5.3、Codex 5.4、GPT 5.5，不展示旧模型名称。
- 修改实现后运行该测试。
- 运行现有视觉主题源码测试，确认黑白灰主题守卫未破坏。
- 确认本地 Vite 5174 热更新可访问。
