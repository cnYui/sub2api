# 风险用户提前一周套餐额度抵销欠费记录

## 授权与范围

管理员授权在无进行中用量时，对本轮筛出的风险用户执行人工结算：若存在尚未到账的下一周余额套餐额度，则提前刷新一周，并按正常周刷新语义优先抵销普通余额欠费。未授权取消套餐、修改支付订单或发起现金退款。

## 执行方式

- 在一个 `SERIALIZABLE` PostgreSQL 事务内锁定用户、套餐和订单记录。
- 仅处理满足「套餐 `active`、下一次刷新尚未到期、仍有后续期数、订单 `COMPLETED` 且未退款」的用户。
- 刷新公式与 `CreditDueBalances` 保持一致：先移除旧窗口剩余（本次均为 `0`），再加入一周额度；欠费优先被抵销，余额为正的部分记为新的本周套餐剩余。
- 每笔写入 `balance_debt_ledger` 还款流水和 `payment_audit_logs` 人工结算审计；不修改订单状态、退款金额或套餐有效期。
