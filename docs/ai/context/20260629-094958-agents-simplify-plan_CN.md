# AGENTS.md 精简计划

## 目标

将根目录 `AGENTS.md` 中的长期有效信息压缩成一份更短的上下文入口，保存到 `docs/ai/context/`。本轮只新增文档，不覆盖、重命名或删除已有历史文件。

## 必须保留

- 协作偏好、实现前设计/计划、上下文落盘、敏感信息禁止记录等工作规则。
- Sub2API 作为唯一公网 API、用户 Key、计费和用量事实源的架构定论。
- 当前公网链路、路由归属、主要端口、18084 与 18080 的运行态区别。
- 支付、订阅、GPT 流量包、SMTP、流量卡兜底、Nginx 请求体上限等仍会影响后续操作的状态。
- Docker/数据库/迁移/候选预演的高风险注意事项。
- Git 远端、上下文文档提交检查等维护规则。

## 压缩策略

- 把逐日流水账改成“当前状态 + 风险约束 + 追溯索引”。
- 保留能直接防止误操作的信息；细节测试过程只保留文档引用。
- 不写完整 API Key、内部 token、HMAC secret、SMTP 密码或 dump 明文内容。
