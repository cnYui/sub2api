# 18080 图片生成模型计费调整到 2.5x 计划

时间：2026-07-26 08:45:08

## 目标

仅将外层 `sub2api-dev`（`127.0.0.1:18080`）的图片生成模型最终基础计费调整为 2.5 倍；不影响文本模型、内层 `18086`、套餐、分组和历史用量。

## 现状与原则

- 当前全局 `billing.unit_price_multiplier` 为 `2.0`。
- `deploy/data/model_pricing.json` 是 18080 容器挂载的运行态价格来源。
- 已对 gpt-5.6 文本模型进行过单项价格定制，且已关闭远程价格同步，运行态修改不会被默认同步覆盖。
- 因全局倍率保留 2.0，目标图片模型的可计费单价应统一乘以 `1.25`，最终为 `2.0 × 1.25 = 2.5` 倍。

## 实施与验证

1. 解析价格文件，识别实际图片生成模型及其所有可计费价格字段。
2. 备份运行态价格文件与哈希文件。
3. 只将识别出的图片模型单价字段乘以 1.25，并更新哈希文件。
4. 重启 `sub2api-dev`，核对健康检查、容器实际加载的价格文件和运行态模型价格。

## 回滚

恢复本次备份的价格文件与哈希文件后重启 `sub2api-dev`；历史用量不会回算。
