## 两个附带事实

### 长上下文档位靠渠道区间定价生效，与账号开关无关

账号 #1169 的 `extra.openai_long_context_billing_enabled` 是 `false`，
但这**不会**导致 ≥200K 少收：`billing_service.go` 的
`applyLongCtx := len(resolved.Intervals) == 0 && *LongContextBillingEnabled`，
而 `resolved.Intervals` 取自渠道级 `model_pricing.intervals`
（`model_pricing_resolver.go:145-149`），渠道 4 三个模型都配了两档，
所以走区间定价分支，账号开关根本不参与。
**别看到这个 false 就去"修"它**——GPT 那批账号要开是因为 GPT 全系没有区间定价行。

### 广场「官方」列对 grok-4.7 是空的

`lookupOfficialPricing` 只查远端 LiteLLM 目录（`pricingService.GetModelPricing`），
目录还没收录 `grok-4.7`，所以 `official_pricing` 为 `nil`、前端显示 `-`。
计费不受影响（渠道级定价是取价第 ① 级，优先于目录）。
要补只能改代码把 grok 并入 `usesCalibratedFallbackPricing` + `fallbackPrices`，
需出镜像，且会改变 4.5/4.6 官方列的取值来源，**未做，待管理员决定**。
