# Claude Max 单条价格复核

## 对照记录

截图对应的模型为 `claude-opus-4-5-20251101`，记录明细为：

- 输入 token：`79`
- 输出 token：`3`
- 缓存读取：页面缩写显示约 `1.9K`
- 输入单价：`$5.00 / 1M Token`
- 输出单价：`$25.00 / 1M Token`
- 缓存读取单价：`$0.50 / 1M Token`
- 中转倍率：`1.50x`
- 页面用户扣费：`$0.002149`

本地价格表对该模型使用相同的 `$5/$25/$0.50` 三档单价；18082 数据库中的 Claude Max 分组倍率为 `1.5000`，最终倍率为 `15`。

## 复算

```text
输入费用 = 79 × 5 / 1,000,000 = 0.000395
输出费用 = 3 × 25 / 1,000,000 = 0.000075
缓存读取费用 = 页面明细显示约 0.000963
标准成本约为 0.000395 + 0.000075 + 0.000963 = 0.001433
中转站实际费用约为 0.001432～0.001433 × 1.5 = 0.002148～0.002150
```

页面原始费用显示 `$0.001432`、用户扣费显示 `$0.002149`。由于缓存 token 和费用字段分别按页面精度显示，复算结果在最后一位存在舍入差异，但与页面金额一致。

若经过本地余额扣费链路，按页面用户扣费计算：

```text
0.002149 × 15 = 0.032235
```

结论：Claude Max 在本地最终 `15x` 之前的费用与别人中转站的用户扣费一致；本地只在该中转站费用基础上再乘 `15x`，没有额外重复乘 `1.5x`。
