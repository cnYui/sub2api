# /purchase 新增 49 元订阅套餐计划

## 背景

用户要求在当前新分支继续新增 49 元订阅档位，同样使用现有 1% 手续费机制。

## 额度推导

沿用前一轮 29 元到 199 元的线性曲线：

```text
slope = (520 - 76) / (199 - 29) = 2.6117647059
limit(price) = 76 + (price - 29) * slope
```

49 元结果为 `128.235... USD/周`，按现有整数 USD 额度口径取 `128 USD/周`，28 天周期总额度为 `512 USD`。

## 命名与兼容

- 现有 `codex-pool-49-usd` 已对应 59 元订阅池，不能作为 49 元档位内部组名。
- 新 49 元档位使用 `codex-pool-128-usd`，和当前 249/299 元新增档位按周额度命名的方式一致。

## 实现范围

- 新增 migration seed：
  - `codex-pool-128-usd` / `49 元订阅池` / `price=49.00` / `weekly_limit_usd=128`
- 后端公共 Codex 周额度映射加入该档，确保下单快照、退款 quote 和管理规范化走现有逻辑。
- Dashboard 当前套餐额度查询白名单加入该档。
- 前端 `/purchase` 额度映射和管理展示名加入该档。
- 补充购买页、前后端额度映射、migration 和退款 quote 测试。
