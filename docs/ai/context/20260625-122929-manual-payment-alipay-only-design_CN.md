# Purchase 手动支付二维码调整设计

## 背景

Purchase 页面里的手动支付弹窗当前同时展示微信支付和支付宝支付两个入口。用户要求下架微信支付图片，只保留支付宝一种支付方式，并把支付宝二维码替换为本次提供的收款图片。

## 目标

- 手动支付弹窗只出现支付宝支付，不再出现微信支付 tab、微信二维码或微信支付入口。
- 弹窗打开后默认直接展示支付宝收款二维码，不需要用户切换支付方式。
- 支付宝二维码资源使用用户提供的新图片。
- 保持现有订单信息、金额展示、付款完成提交态和兑换码跳转行为不变。

## 设计

- 修改 `frontend/src/components/payment/ManualPaymentDialog.vue`，删除支付方式切换状态和微信二维码渲染分支，保留单个支付宝二维码区域。
- 修改 `frontend/src/components/payment/__tests__/ManualPaymentDialog.spec.ts`，把测试从“默认微信、可切换支付宝”改为“仅存在支付宝、不存在微信入口”。
- 将新的支付宝二维码作为静态前端资源引入，组件继续通过资源 import 引用，避免运行时依赖外部图片地址。

## 取舍

- 不删除旧的微信二维码资产文件，避免这次小变更制造无关文件删除；只从组件渲染链路下架微信支付。
- 不改支付后端和 ZPay API 链路，这次需求只针对 Purchase 手动二维码前端页面。

## 验证

- 先运行目标组件测试确认新断言会在旧实现下失败。
- 修改组件和资源后重新运行目标组件测试。
- 再运行前端类型检查，确认模板和 TS 引用没有残留错误。
