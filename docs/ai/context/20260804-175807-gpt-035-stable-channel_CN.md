# GPT 0.35 倍稳定渠道接入记录

## 目标

在 18082 生产实例新增“GPT模型官方0.35倍稳定”渠道，并使所有用户可在 API Key 页面选择。

## 实现

- 创建公开、活跃、标准类型的 OpenAI 分组，分组倍率为 `0.35`。
- 新增一个可调度的 OpenAI API Key 账号并仅绑定到该分组；并发为 `10`、优先级为 `1`。
- 账号复用现有“GPT模型官方0.15倍价格”渠道的 GPT 模型映射和模型列表，避免手工维护两套模型范围。
- 账号统计倍率设为 `3.5`，与现有渠道的“分组倍率 × 10”统计口径一致；它不改变用户 API Key 的分组扣费倍率。
- 上游地址为既有 GPT 渠道使用的 `https://api.ai-genesis.app`。
- 提供的上游密钥只写入生产数据库的账号凭证，未写入仓库、迁移脚本或本文档。

## 用户可见性

用户 API Key 页面通过 `/groups/available` 读取可选分组。服务端会向每个用户返回活跃的公开标准分组；新分组不是专属分组，也不是订阅分组，因此无需修改前端或额外授权，即可出现在选择器中。

## 验证

- 上游 `/v1/sub2api/billing` 返回 `resolved_rate_multiplier=0.35` 和 `effective_rate_multiplier=0.35`。
- 数据库核验分组 ID 为 `10`，状态为 `active`，已绑定一个活跃、可调度的 OpenAI API Key 账号；模型映射字段存在。
- 应用容器已重启以刷新运行时缓存，`http://127.0.0.1:18082/health` 返回 `{"status":"ok"}`，容器健康状态为 `healthy`。
