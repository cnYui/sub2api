# 购买页商品卡自适应修复

## 背景

购买页统一半透明卡片样式后，固定的多列规则在较窄页面中会压缩卡片宽度，中文标题和明细容易逐字换行，影响扫描和购买操作。

## 决策

- 商品目录统一使用 `purchase-catalog-grid`，以 `repeat(auto-fit, minmax(min(100%, 280px), 1fr))` 根据容器宽度自动换列。
- 桌面视口使用 `2rem` 间距，小屏使用 `1.5rem`，保持卡片之间的呼吸感。
- 商品标题允许按词换行，价格和购买按钮保持不换行；明细使用稳定的“标签 + 值”两列，值列限制最大宽度后再按合理边界换行。
- 删除仅用于视觉核对的 `/purchase-preview` 临时路由和视图，正式 `/purchase` 仍由服务端商品数据驱动。

## 验证

- 内置浏览器默认视口：真实余额套餐与流量卡卡片可正常显示，桌面宽度下自动排列。
- 窄桌面视口：卡片在可用区域内保持可读，标题、价格、明细和按钮未出现逐字换行。
- 手机等效窄视口：网格降为单列，卡片内容不溢出；测试完成后已恢复默认视口。
