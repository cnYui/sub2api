# 2026-07-21 月总额度与 35% 毛利定价测算

## 假设

- 用户问题按“取消每日刷新，改为购买后一次性发放一个月总额度”理解。
- 当前削减后的日额度等价换算为月总额度：`月总额度 = 日额度 * 30`。
- 成本假设：1 个 Plus 账号可承载 `150 USD/天`，采购成本 `12 RMB/天`。
- 成本单价：`12 / 150 = 0.08 RMB/USD`。
- 35% 利润点按毛利率口径：`利润 / 收入 = 35%`，因此 `成本 = 收入 * 65%`。

## 公式

```text
月成本 = 月额度USD * 0.08
35%毛利所需月价 = 月成本 / 0.65
```

如果仍用“日额度等价”表示：

```text
35%毛利所需月价 = 日额度USD * 30 * 0.08 / 0.65
                = 日额度USD * 3.6923077
```

## 风险判断

- 月总额度不会降低满额成本；只是把“每天刷新”改成“整月余额池”。
- 月总额度会提升用户把未使用额度集中消耗掉的能力，实际成本可能比每日刷新更高。
- 如果取消日硬限制，用户可以月初一天用完整月额度，会造成账号池当天承载压力暴涨。
- 建议即使卖月总额度，也保留：
  - 分组 RPM/并发限制。
  - 单日软限或单日最大消耗比例，例如每日最多使用月额度的 20%-30%。
  - 月额度用尽即停，不再自动透支；如果要透支，必须明确显示为次月扣减或流量卡扣减。
