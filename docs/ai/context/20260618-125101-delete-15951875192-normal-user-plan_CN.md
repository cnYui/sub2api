# 删除 15951875192 普通用户执行计划

## 背景

用户要求使用现有管理员账号删除 Sub2API 中手机号 `15951875192` 对应的普通用户账号。

当前迁移体系里，该手机号在 Sub2API 中的登录邮箱为：

```text
15951875192@phone.com
```

本次操作不把该用户提升为管理员，不重置该用户密码，只删除这个普通用户及其名下 API Key。

## 边界

- 操作主体：现有 Sub2API 管理员账号。
- 目标用户：`users.email = '15951875192@phone.com'`，且必须不是 `admin` 角色。
- 删除路径：优先通过 `/api/v1/admin/users/:id` 管理接口执行。
- 数据保护：删除前先备份当前 Sub2API PostgreSQL 数据库。
- 安全要求：文档和最终回复不记录完整管理员密码、JWT、完整 API Key 或数据库密码。

## 预期业务行为

代码中 `AdminService.DeleteUser()` 的行为是：

1. 先读取用户。
2. 如果用户角色为 `admin`，直接拒绝删除。
3. 列出该用户名下 API Key。
4. 对每个 API Key 调用 `DeleteWithAudit()`。
5. 删除用户记录。
6. 清理该用户和相关 API Key 的认证缓存。

因此本次通过管理接口删除，可以同时处理 API Key 审计和缓存失效，不直接绕过业务层改表。

## 验收项

- 数据库备份文件存在且非空。
- 管理员登录接口返回有效 access token。
- 删除前能定位到目标用户，且角色不是 `admin`。
- 删除接口返回成功。
- 删除后管理用户列表查不到该目标用户。
- 目标用户原 API Key 访问 `/v1/models` 不再返回 200。
- 新增结果文档并更新 `AGENTS.md`。
