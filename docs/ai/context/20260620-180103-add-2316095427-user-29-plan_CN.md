# 添加 2316095427@qq.com 用户到 29 元套餐计划

## 目标

- 直接在当前 Sub2API 运行库中创建用户 `2316095427@qq.com`，不要求用户手动注册。
- 使用用户指定的初始密码生成 bcrypt 哈希；文档不记录明文密码。
- 绑定当前售卖配置中的 29 元/月套餐，并创建一个默认 API Key 用于立即使用。

## 当前确认

- `users` 中不存在 `2316095427@qq.com` 对应用户。
- `auth_identities` 中不存在 `2316095427@qq.com` 对应 email 身份。
- 当前 29 元/月售卖套餐为：
  - `subscription_plans.id=1`
  - `name=29 元订阅池`
  - `price=29.00`
  - `validity_days=30`
  - `group_id=2`
  - `group_name=codex-pool-19-usd`
  - `daily_limit_usd=19`
- `codex-pool-29-usd` 实际对应 `39 元订阅池`，不是本次用户要求的 29 元/月套餐。
- `group_id=2` 当前 active，且已绑定 active 上游账号 `cliproxy-local-openai`。

## 设计

采用最小事务写入：

1. 生成 bcrypt 密码哈希。
2. 生成随机 `sk-` API Key。
3. 在单个 PostgreSQL 事务中写入：
   - `users`
   - `auth_identities`
   - `user_subscriptions`
   - `api_keys`
4. 订阅起始时间使用数据库当前时间，过期时间为起始时间加 30 天。
5. `assigned_by` 使用当前系统管理员 `users.id=1`，便于审计。

- 不改默认注册、邮箱验证、支付配置。
- 不记录完整 API Key、密码 hash 或明文密码到文档、提交、日志。
