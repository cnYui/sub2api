# Codex 新生产路径配置

## 背景

管理员要求将现有 Codex 新生产渠道区分为路径 1，并基于相同上游端点新增路径 2。

## 配置原则

- 路径 1：将现有账号名称改为“Codex新（生产路径1）”。
- 路径 2：创建名称为“Codex新（生产路径2）”的独立 OpenAI API Key 账号。
- 路径 2 复用路径 1 的模型白名单、`Codex新（生产）`分组、调度并发、优先级及相关渠道策略。
- 路径 2 使用管理员提供的独立上游 API Key，凭证仅通过服务端加密存储；本文档不记录密钥。
- 先通过“复制账号”创建不可调度副本，再替换独立凭证并启用，避免副本在凭证更新前承接路径 1 的流量。

## 验证

- 创建完成后核对两个账号的名称、分组、模型数、启用状态与可调度状态。
- 由服务端在新凭证保存后自动异步探测 OpenAI Responses API 支持能力。
