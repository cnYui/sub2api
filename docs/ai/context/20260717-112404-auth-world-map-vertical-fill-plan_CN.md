# 认证页地图纵向全填充计划

## 目标

将登录与注册页的世界地图从固定 `1800×900` 背景改为按认证页面实际高度缩放，使主要大陆点阵连接页面顶部和底部，并在桌面、移动端和较长注册页中保持纵向填充。

## 实现

- 仅修改 `WorldMapBackground.vue` 和对应视觉契约测试。
- 用 3 张相同的装饰性 `<img>` 替代固定尺寸 CSS background。
- 地图轨道高度设为容器的 `125%`，通过 `top: 50%` 和 `translateY(-50%)` 垂直居中裁切。
- 图片保持原始 2:1 比例，轨道宽度由图片自然宽度决定。
- 轨道向左移动自身宽度的 `33.333333%`，即一个地图周期；3 张图片保证动画过程中常见超宽视口不露空白。
- 动画周期调整为 `75s`，保持接近参考实现的滚动速度。
- 减少动态效果时停止横向动画，但保留垂直居中 transform。

## 范围

- 不修改 `AuthLayout`、登录/注册表单、认证接口或地图纹理资源。
- 不扩展到忘记密码、OAuth 回调等其他认证页面。
- 不修复完整前端套件中已确认的 11 个无关基线失败。

## 验证

- 先更新视觉契约测试并确认 RED，再实现组件并确认 GREEN。
- 运行认证布局目标测试、类型检查、生产构建和目标文件 ESLint。
- 检查桌面、移动端和较长页面下轨道高度为容器的 125%，无水平空白、表单无遮挡。
- 完成后新增 result 上下文，不覆写历史文档。
