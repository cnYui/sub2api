## 对照记录

截图对应模型为 `grok-4.20-0309-reasoning`，记录明细为：

- 输入 token：`108`
- 输出 token：`238`
- 缓存读取：`128`
- 输入单价：`$1.25 / 1M Token`
- 输出单价：`$2.50 / 1M Token`
- 缓存读取单价：`$0.20 / 1M Token`
- 中转倍率：`0.60x`

本地计费回退价格对 Grok 4.20 使用相同的 `$1.25/$2.50/$0.20` 三档单价；18082 数据库中的 Grok 分组倍率为 `0.6000`，最终倍率为 `15`。

## 复算

```text
输入费用 = 108 × 1.25 / 1,000,000 = 0.0001350
输出费用 = 238 × 2.50 / 1,000,000 = 0.0005950
缓存读取费用 = 128 × 0.20 / 1,000,000 = 0.0000256
标准成本 = 0.0001350 + 0.0005950 + 0.0000256 = 0.0007556
中转站实际费用 = 0.0007556 × 0.60 = 0.00045336
```

页面按六位小数显示为 `$0.000756`、`$0.000453`，与复算一致。若经过本地余额扣费链路，未四舍五入的最终扣费约为：

```text
0.00045336 × 15 = 0.00680040
```

结论：Grok 在本地最终 `15x` 之前的费用与别人中转站的用户扣费一致；本地只在该中转站费用基础上再乘 `15x`，没有额外重复乘 `0.6x`。
