# /admin/groups 与 /admin/subscriptions 分组名称显示调整计划

## 背景

当前管理页把公共 Codex 订阅分组直接显示为内部 `codex-pool-xx-usd` 名称，和最近已调整后的额度口径不一致。用户希望管理页展示改为当前人民币价格名，例如 `29 元订阅池`、`39 元订阅池`、`199 元订阅池`。

## 目标

- `/admin/groups` 的分组名称展示改为人民币套餐名。
- `/admin/subscriptions` 中分组相关展示同步改为同一套名称。
- 保留内部 `group.name` 作为业务标识，不改数据库标识。

## 方案

- 在前端提取一个统一的分组展示名工具。
- 仅对已知公共 Codex 订阅分组做价格名映射，其他分组保持原名。
- 同步替换两个页面里的表格单元格、筛选项和下拉选项展示。

## 风险

- 只改展示，不改内部标识，避免影响支付、路由和历史事实。
- 如果后续需要让“搜索”也按人民币名命中，再单独补搜索映射，不在本次顺手扩大范围。
