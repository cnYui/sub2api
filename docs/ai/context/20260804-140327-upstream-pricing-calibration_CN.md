# 中转站价格口径校准

## 目标

本地在隐藏的最终 `15x` 之前，按同一模型、同一 token 数量计算出的费用必须等于 `api.ai-genesis.app/usage` 中转站的“实际”费用；用户余额最终扣除额为该费用再乘 `15`。

## 已修正的线上配置

- `GLM模型官方0.2折价格`：`1.4x` → `3.5x`。
- `DeepSeek模型官方0.42折价格`：`3.0x` → `3.5x`。
- Kimi、Claude Max、Claude Kiro、Grok、GPT 保持中转站明细中已核对的 `3.5x / 1.5x / 0.35x / 0.6x / 0.15x`。
- `BILLING_FINAL_MULTIPLIER=15` 保持不变。
- 本地动态/兜底标准单价无需改动；抽样记录已经证明它们与中转站明细的输入输出单价一致。

## 最终公式

```text
standard_cost = token × 官方/中转站标准单价
upstream_equivalent_cost = standard_cost × 分组中转倍率
user_balance_charge = upstream_equivalent_cost × 15
```

例如 Kimi K3：

```text
0.001134 × 3.5 = 0.003969（与中转站实际费用相同）
0.003969 × 15 = 0.059535（本地余额扣费）
```

历史 `usage_logs` 不重算；新请求从应用重启后使用新倍率。重启后 `http://127.0.0.1:18082/health` 返回 `200`，容器环境仍为 `BILLING_FINAL_MULTIPLIER=15`。
