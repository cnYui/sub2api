DeepSeek 由 `3.5x` 提到 `4.9x` 是涨价 `1.4` 倍，与「5 折→7 折」的口径一致。

## 影响范围

- 用户实际扣费仍为 `标准成本 × 分组倍率 × 18`（隐藏最终倍率未改）。
- Claude 与 DeepSeek 的调整对**新发生的请求**生效；历史 `usage_logs` 保留下单时的倍率快照，未改写。
- 下架的两个分组状态为 `停用`：用户创建 API Key 时不再可选。
  已绑定这两个分组的存量 API Key 会随之不可用，如需保留存量用户，
  应先把这些 Key 迁移到其他分组，或把分组状态改回「正常」（该操作可逆）。
- 未修改任何上游账号凭证、账号与分组的绑定关系、用户余额、订单、退款或历史用量。
