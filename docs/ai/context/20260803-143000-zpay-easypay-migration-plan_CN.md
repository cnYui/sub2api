# ZPay 易支付迁移记录

## 目标

将本仓库运行在 `18082` 的官方版本补齐 ZPay/EasyPay 兼容能力，并按用户明确授权复用 `18080` 参考实例的 ZPay 商户凭证。

## 运行态边界

- ZPay 通过现有 `easypay` provider 接入，不新增独立 provider。
- 支付宝通道使用 `payment_mode=popup`，由 ZPay `submit.php` 托管收银台负责展示付款页。
- 参考实例只启用支付宝可见支付方式；微信支付保持关闭。
- 当前参考实例已开启服务端退款及用户退款，因此迁移执行时显式带上对应开关。
- 凭证仅在当前进程的内存变量中从参考数据库传入配置脚本；不会写入仓库、文档或命令输出。
- 不创建真实支付订单，避免将本地 `18082` 的订单回调到参考站点。

## 代码兼容范围

- 后端解析 ZPay `mapi.php` 的 `img` 二维码图片字段，并通过 `qr_image_url` 返回。
- 前端在没有二维码文本时直接展示服务商二维码图片，并将地址写入本地恢复快照。
- 新增可重复执行的运行态配置脚本，默认 dry-run；只有显式 `--apply` 才会改写目标 PostgreSQL。
