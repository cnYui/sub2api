# GPT 与 Kimi 分组倍率交叉核对

## 核对结果

上游 `api.ai-genesis.app/usage` 的 GPT API Key 汇总显示：

- 标准费用：`$272.0701`
- 实际费用：`$40.8105`
- 实际 / 标准：约 `0.15x`

18082 本地用户 `2799523972@qq.com` 的 GPT 记录 `usage_logs.id=286781`：

- `total_cost=0.001928`
- `rate_multiplier=0.15`
- `actual_cost=0.004338`
- 公式：`0.001928 × 0.15 × 15 = 0.004338`

该结果与“上游实际费用 × 15”一致。若把 GPT 分组倍率改为 `1`，同一基础成本将扣 `0.02892`，相对目标多收约 `6.67x`。

此前核对的 Kimi K3 记录同样是基础成本 `0.0536268`、分组倍率 `3.5`、最终扣费 `2.815407`，公式为 `0.0536268 × 3.5 × 15`；上游 K3 的标准/实际比例也是 `3.5x`。

## 决策

“把所有分组倍率设为 1”不符合“上游已经算出实际费用，再乘本地 15 倍”的目标，因为 `usage_logs.total_cost` 是本地标准模型成本，不是上游实际费用。恢复原有分组倍率，让它承担上游模型价格口径；`BILLING_FINAL_MULTIPLIER=15` 继续承担本地加价。
