# 流量卡在每日套餐额度耗尽后无法扣费排查计划

## 背景

用户反馈：已添加流量卡的用户在每日套餐额度用完后，流量卡无法继续使用，也没有发生扣费。

## 必须确认的问题

- 本地 `main` 代码中，套餐额度检查失败后是否会查询并放行 OpenAI/GPT 流量卡。
- 请求完成后的用量落库阶段是否会把本次费用记到 `TrafficPackCost` 并执行 FIFO 扣减。
- 流量卡设计文档与当前代码是否一致，特别是“订阅优先、额度耗尽后扣流量卡”的设计。
- 当前运行态数据库中，用户流量卡、订阅用量、流水是否符合代码预期。

## 排查步骤

1. 阅读 `docs/ai/context` 中 GPT 流量包设计、实现、历史行为调查和赠送记录。
2. 从本地 `main` 代码反向追踪：API Key 分组资格检查、订阅限额检查、流量卡放行、用量计费、流量卡扣减。
3. 查询当前容器/数据库状态，验证用户实际数据和是否已有扣费流水。
4. 形成单一根因假设，并用最小命令或测试验证。
5. 只在确认根因后再决定是否需要代码修复；本阶段先不修改业务代码。

## 风险约束

- 不记录完整 API Key、内部 token、SMTP 密码等敏感信息。
- 不覆写、重命名或删除历史上下文文件。
- 不回滚用户已有工作区改动。
