# 全渠道模型计费倍率复核与加价层更正

## 统一口径

用户最新确认的平台计费基准是中转站原始标准成本再乘本地最终 `15x`：

```text
本平台用户扣费 = 标准成本 × 15
```

上游中转站页面已经显示的加价用户费用（例如 Kimi、GLM、DeepSeek 的 `3.5x`）不再作为本平台用户余额的第二层倍率。上游折扣倍率仍需保留，否则会把折扣渠道价格抬高。
