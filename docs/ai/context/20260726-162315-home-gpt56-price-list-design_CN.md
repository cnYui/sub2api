# 首页 GPT-5.6 与价格清单设计

## 背景

默认首页将支持模型写死为 GPT 5.3、Codex 5.4、GPT 5.5，并仅通过四个功能卡片展示部分订阅档位。当前购买页在登录后从 `GET /api/v1/payment/checkout-info` 读取在售商品；该接口受 JWT 保护，匿名首页不能调用。

2026-07-26 从外层 `sub2api-postgres-dev` 运行态核对到的在售商品如下：

- 订阅套餐：29、39、49、59、79、99、149、199、249、299 元，均为 28 天。
- GPT 流量卡：5 刀额度售 2 元、10 刀额度售 3 元、20 刀额度售 5 元，均为 365 天。

## 决策

按用户明确选择，采用纯前端静态清单：不新增公共商品接口，不修改购买页、支付逻辑或数据库。

首页替换全部 GPT 5.3 / Codex 5.4 / GPT 5.5 模型标签，展示 `gpt-5.6-luna`、`gpt-5.6-sol`、`gpt-5.6-terra`。在模型区之后新增价格区，使用数据数组渲染 10 个订阅套餐与 3 个流量卡；每张价格卡跳转登录页或购买页，与首页现有 CTA 的认证行为一致。

## 取舍与维护约束

静态方案改动小、无需改变匿名 API 边界，但后台修改价格、有效期、商品名称或在售状态后，首页不会自动同步。此时必须同步更新 `frontend/src/views/HomeView.vue` 的静态商品数组和对应测试。若未来需要自动同步，应单独新增仅暴露公开商品字段的目录接口，不能公开现有 `checkout-info`，因为后者包含支付方式与限额配置。

## 验收标准

- 首页不再显示 GPT 5.3、Codex 5.4 或 GPT 5.5。
- 首页显示三个 GPT-5.6 模型标识。
- 首页完整显示 10 档订阅价格与 3 张流量卡的售价、额度和有效期。
- 未登录用户点击价格卡前往 `/login`，已登录用户前往 `/purchase`。
- 现有首页内容覆盖与主题行为不回归。
