## 原始录屏里有敏感内容，不能原样发布（本次最重要的发现）

仓库是公开的，教程页也是公开可访问的，所以发布前逐帧检查了。原始视频里有：

1. **完整的 API Key 明文**：用户消息气泡里整把 Key（约 2.4–12.2 秒，窗口变宽、滚动时位置会变）、标题栏里 `sk-c79093c…` 前缀（2.4 秒到结尾，刚输入时还有更长的一段）、粘贴到输入框的那一瞬间。
2. **后台「API 密钥」页面**闪现两次（约 1.97–2.10 与 2.30–2.37 秒）：带账号邮箱、余额、浏览器标签页标题。
3. 右上角网页后面露出的**账号邮箱**（0–8 秒，窗口变宽后被盖住）。
4. 桌面图标文件名、任务栏（没处理，不是凭据）。

**处理方式**：ffmpeg 一遍过——缩放到 1280 宽 → `drawbox`（带 `enable='between(t,a,b)'`）按时间段盖住 Key 所在位置，稳定阶段的气泡第二行盖上「API Key 已隐藏」标签，窗口变宽和滚动阶段整块盖住 → 用 `select` + `setpts` 把后台页那两小段（1.9–2.45 秒）整段剪掉 →
`libx264 -preset slow -crf 27 -pix_fmt yuv420p -movflags +faststart -an`。音轨是纯静音（-91 dB），直接去掉。
**必须在成片（不是中间版）上验证**：按时间把标题栏、气泡区、输入框、邮箱区各截成条带逐帧看，确认没有任何 Key 字符；第一版标题框只盖到 x=833，漏掉了 2.5–2.8 秒的更长前缀，是验证时才发现的，加宽到 940 才干净。

**那把 Key 已经暴露在原始文件里**（微信目录里的 `_raw.mp4`，可能已经发给过别人）。它绑在分组「GPT生图1倍率」上，建议管理员在「API 密钥」里删除或轮换。本次没有动它。

## 以后加视频要守的规矩

- **原始录屏一律先逐帧查 Key / 邮箱 / 余额 / 其它账号信息**，用 `ffmpeg -vf fps=4,...,tile=` 生成带时间戳的拼图来看；浏览器切换、窗口缩放、滚动都会让敏感位置变化，别只看几张静态帧。
- 录屏时直接用打码的 Key、或建一个设了额度上限的临时 Key，用完删掉，比事后遮挡可靠得多。
- 视频随前端打进镜像并进 git 历史，**体积要小**：测试里卡了 mp4 < 2 MB、封面 < 200 KB。现有 CCSwitch 视频是 3.1 MB / 116 秒。
- 内容过时后（分组改名、模型增减）要重录或删掉，教程文字里写的是「GPT生图1倍率」和 `gpt-image-2`，视频里是 Codex 桌面端和它自带的生图技能，两者都可能变。
