# GLM 单条价格复核

## 浏览器记录

在 `api.ai-genesis.app/usage` 的 API Key `GLM` 明细中，截图对应记录为：

- 模型：`glm-5.1`
- 输入 token：`62`
- 输出 token：`128`
- 输入单价：`$1.40 / 1M Token`
- 输出单价：`$4.40 / 1M Token`
- 中转倍率：`3.5x`
- 页面用户扣费：`$0.002275`

## 复算

```text
输入费用 = 62 × 1.40 / 1,000,000 = 0.0000868
输出费用 = 128 × 4.40 / 1,000,000 = 0.0005632
标准成本 = 0.0000868 + 0.0005632 = 0.000650
中转站实际费用 = 0.000650 × 3.5 = 0.002275
```

结论：本地在最终 `15x` 之前的 GLM 费用与别人中转站页面完全相同；本地余额最终扣费为 `0.002275 × 15 = $0.034125`。
