# 认证页地图纵向全填充结果

## 结果

登录与注册页的世界地图背景已从固定尺寸 CSS 纹理改为 3 张相同图片组成的循环轨道。轨道按认证页面实际高度缩放为 `125%` 并垂直居中裁切，桌面、移动端和长页面下均覆盖完整背景容器，不再受固定 `1800x900` 尺寸限制。

## 改动

- `WorldMapBackground.vue` 使用 3 张装饰性 `<img>` 横向排列，保留原地图资源、颜色和点距。
- 地图轨道使用 `top: 50%`、`height: 125%` 和 `translate3d(0, -50%, 0)`。
- 横向动画在 `75s` 内移动轨道宽度的 `-33.333333%`，即一张地图的完整宽度。
- 图片保持原始 `2:1` 比例并随容器高度缩放。
- `prefers-reduced-motion` 下停止动画，同时保留垂直居中变换。
- 更新视觉契约测试，覆盖图片数量、纵向比例、循环距离、周期和减少动态效果模式。

## 浏览器验收

使用本机 Chrome 和精确 Playwright 视口验证：

- `1548x954` 登录页：背景 `1548x954`，轨道 `7155x1192.5`，高度比 `1.25`；3 张图片；页面 `scrollWidth === clientWidth === 1548`；当前动画位置和循环终点的理论覆盖范围均无水平空白；表单完整位于页面内。
- `390x844` 登录页：背景 `390x844`，轨道 `6330x1055`，高度比 `1.25`；页面 `scrollWidth === clientWidth === 390`；表单无遮挡。
- `390x844` 注册页：背景和轨道保持相同比例，无水平溢出，表单无遮挡。
- 长注册页模拟：页面滚动高度增至 `1280px` 后，背景同步为 `1280px`，轨道为 `1600px`，高度比仍为 `1.25`，底部未出现固定尺寸造成的黑带。
- 减少动态效果：动画名称为 `none`，轨道垂直中心偏差为 `0`。
