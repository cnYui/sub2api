# SMTP 配置迁移记录

时间：2026-08-03

## 变更

- 将本机 `18080` 实例中已存在的 7 项 SMTP 设置定向复制到 `18082` 实例。
- 使用数据库临时表和按键 upsert，仅涉及 SMTP 主机、端口、用户名、密码、发件人、发件人名称与 TLS 开关。
- 未修改其他系统设置、用户数据、渠道数据或上游凭证。

## 验证

- 源实例与目标实例均存在 7 项 SMTP 设置。
- 对每项值进行不可逆指纹比对，结果一致。
- `http://127.0.0.1:18082/health` 返回 HTTP 200。
- 邮件服务在每次发送时从设置库读取 SMTP 配置，因此无需重启应用。

## 限制

- 未通过管理后台执行 SMTP 连通性测试：当前自动化环境无法连接浏览器会话，且不应以未知收件人触发实际邮件。
- 后续由管理员在 `18082` 的 SMTP 设置页执行“测试连接”或发送测试邮件，以完成真实认证与投递验证。
