# GPT 低价与 GPT-Image-2 渠道接入记录

## 目标

在 18082 生产实例新增两个用户可选渠道：

- `GPT0模型官方0.1倍低价不稳定`
- `GPT-Image-2生图`

## 实现

- 两个渠道均为活跃、非专属、标准类型的 OpenAI 分组，因此用户 API Key 页面会通过既有 `/groups/available` 自动加载，无需修改前端。
- `GPT0模型官方0.1倍低价不稳定` 的分组倍率为 `0.1`，账号统计倍率为 `1`。上游模型列表确认可用的非图像模型为 `codex-auto-review`、`gpt-5.5`、`gpt-5.6-luna`、`gpt-5.6-sol`、`gpt-5.6-terra`，分组模型列表和账号映射均限制为这五个模型。
- `GPT-Image-2生图` 的分组倍率为 `1`，账号统计倍率为 `10`，仅映射并只在 `/v1/models` 返回 `gpt-image-2`；同时开启 `allow_image_generation`，使 `/v1/images/*` 和图像意图请求可正常通过分组权限检查。
- 两个上游账号使用既有 GPT 渠道的上游地址，并分别独立绑定到自己的分组；密钥只写入生产数据库账号凭证，不写入仓库或本文档。

## 定价隔离决策

低价 GPT 上游密钥的模型列表还包含 `gpt-image-1.5` 和 `gpt-image-2`，但没有将图像模型放入 `0.1x` 渠道。独立生图渠道的倍率是 `1x`，若低价渠道同时公开图像模型，用户可绕过独立生图渠道的定价。故低价分组只开放文本/Codex 模型，图像生成统一使用 `GPT-Image-2生图`。

## 验证

- 两个上游 `/v1/sub2api/billing` 响应分别确认有效倍率为 `0.1` 和 `1`。
- 上游 `/v1/models` 确认低价密钥可读取 7 个模型，生图密钥只返回 `gpt-image-2`。
- 数据库核验：分组 ID `11` 和 `12` 均已绑定一个活跃、可调度的 OpenAI API Key 账号；低价分组模型列表为 5 个非图像模型，生图分组模型列表为 1 个图像模型且已开启图像生成权限。
- 应用容器已重启以刷新运行时缓存，健康检查返回 `{"status":"ok"}`。
- 未发送真实生成请求，避免在未要求时产生模型费用。
