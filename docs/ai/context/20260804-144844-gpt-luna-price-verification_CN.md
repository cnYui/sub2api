# GPT Luna 单条价格复核

## 对照记录

截图对应模型为 `gpt-5.6-luna`，记录明细为：

- 输入 token：`596`
- 输出 token：`5`
- 缓存读取：页面缩写显示约 `3.8K`
- 输入单价：`$0.20 / 1M Token`
- 输出单价：`$1.20 / 1M Token`
- 缓存读取单价：`$0.02 / 1M Token`
- 中转倍率：`0.15x`
- 页面用户扣费：`$0.000030`

本地 `gpt-5.6-luna` 价格表使用相同的 `$0.20/$1.20/$0.02` 三档单价；18082 数据库中的 GPT 分组倍率为 `0.1500`，最终倍率为 `15`。

## 复算

```text
输入费用 = 596 × 0.20 / 1,000,000 = 0.0001192
输出费用 = 5 × 1.20 / 1,000,000 = 0.0000060
缓存读取费用 = 页面明细显示约 0.000077
标准成本 = 0.0001192 + 0.0000060 + 0.0000770 = 0.0002022
中转站实际费用 = 0.0002022 × 0.15 = 0.00003033
```

页面按六位小数显示为 `$0.000202` 和 `$0.000030`，与复算一致。若经过本地余额扣费链路，未四舍五入的最终扣费约为：

```text
0.00003033 × 15 = 0.00045495
```

结论：GPT Luna 在本地最终 `15x` 之前的费用与别人中转站的用户扣费一致；本地只在该中转站费用基础上再乘 `15x`，没有额外重复乘 `0.15x`。
