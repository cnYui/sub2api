# 订阅卡片价格与描述精简计划

## 背景

用户指出购买页订阅卡片当前用 `$` 和 `/30` 展示价格，容易让人误解为美元计价；卡片内额度、周期、倍率等重复信息也偏多。

## 修改边界

- 只修改前端展示文案、订阅卡片 UI 和前端测试。
- 不修改后端接口、套餐真实价格、日限额、订阅有效期、订单创建、支付或计费逻辑。
- 保持现有卡片布局风格，不做大幅视觉重排。

## 目标格式

- 右侧价格：`¥29元`、`¥39元`、`¥59元`。
- 卡片描述：`月度订阅-时间 30天，日限额 19刀，24点刷新`，39 元和 59 元分别对应 29 刀、49 刀。
- 按钮继续使用「立即开通」。
- 移除卡片中重复的美元价格、`/30` 周期、倍率、模型 scope、features 等冗余说明。

## 验证计划

- 先补 `SubscriptionPlanCard` 回归测试，确认旧实现红灯。
- 修改组件后运行该测试确认绿灯。
- 运行购买页、首页和主题来源相关测试。
- 运行前端构建与 `git diff --check`。
