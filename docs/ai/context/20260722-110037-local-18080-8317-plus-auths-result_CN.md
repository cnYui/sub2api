## 公网状态

- 当前 Windows 本地虽然已经提供 `127.0.0.1:8080`，但公网仍显示：
  - `https://aaccx.pw/shop`：200，标题仍是 `Shop - Yui's Portfolio`
  - `https://api.aaccx.pw/health`：Cloudflare 502
- 结论：公网 Cloudflare Tunnel/nginx 实际入口不在当前 Windows 运行态中，或仍指向用户描述的 macOS 入口。要完成公网映射，需要在实际运行 cloudflared 与 nginx 的 macOS 主机上执行：
  - 确认 `cloudflared` 仍把 `aaccx.pw/www/api` 转到 `127.0.0.1:8080`
  - 确认 Homebrew nginx 监听 `8080`
  - 将 nginx 中 Sub2API upstream 从 `127.0.0.1:18084` 改到 `127.0.0.1:18080`
  - 或者在该 macOS 主机启动 Sub2API 到当前 nginx 配置要求的 `18084`
