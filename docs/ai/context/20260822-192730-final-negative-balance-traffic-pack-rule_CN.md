# 最终负余额流量卡规则

## 最终规则

1. 普通余额 `>=0` 时始终使用普通余额，不切换流量卡；包括 `0.01 USD` 以下的正余额，也不再设置额外保底阈值。
2. 普通余额 `<0` 后，下一次请求不得继续扣普通余额，必须切换到用户级全渠道流量卡。
3. 流量卡净额度必须严格 `>0` 才允许发起一次调用。调用完成后，如果流量卡净额度归零或本次产生流量卡欠费，下一次请求自动拒绝。
4. 余额和流量卡均不满足条件时返回余额不足，规则对所有用户、主 API、Gemini 原生 API 和 Antigravity Gemini 入口统一生效。
