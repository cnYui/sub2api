# 登录页品牌名称修正

## 原因

登录页由 `AuthLayout.vue` 独立渲染，并直接读取运行时公共设置中的 `site_name`。该设置仍为 `Sub2API`，因此此前修改主页和侧栏后，登录页标题仍显示旧名称。

## 修改

- 登录页改为使用 `LOCAL_SITE_NAME`，固定显示“天才程序员小站”。
- 保留当前站点图标和英文副标题，不修改后端公共设置或持久化数据。

- 18082 应用镜像：`sha256:82e5b0959574512b470c2aa18bc4ffb9f645656fac1f04318b64462c0810115f`。
- `sub2api-official-18082` 状态 `healthy`，`GET /health` 返回 HTTP 200。
- 验证浏览器已有登录态，访问 `/login` 自动重定向至控制台；无法在该会话中直接显示未登录页面，但打包产物包含修改后的登录页组件。
