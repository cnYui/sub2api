# 登录与注册页循环世界地图背景设计

## 背景

当前登录与注册页通过 `frontend/src/components/layout/AuthLayout.vue` 共用认证布局，页面背景在深色主题下为纯黑。目标是参考 `yui.web/projects/index.html` 中“我的技术之旅”区域，为登录和注册页增加持续水平循环的紫色点阵世界地图。

参考实现使用 Canvas 读取约 965 KB 的 `custom.geo.json`，按固定经纬度网格判断陆地并逐帧重绘。该方式适合展示页，但认证页只需要装饰性背景，没有必要承担 GeoJSON 下载、解析和逐帧采样成本。

## 已确认范围

- 仅登录页和注册页启用世界地图背景。
- 忘记密码、重置密码、邮箱验证、OAuth 回调等其他复用 `AuthLayout` 的页面保持现状。
- 亮色和深色主题下，登录与注册页都使用深色地图背景。
- 不修改表单字段、认证业务逻辑、路由或后端接口。

## 方案选择

采用“预渲染点阵纹理 + CSS 位移动画”。

- 以 `yui.web/custom.geo.json` 为地图来源，沿用参考实现的等距圆点、紫色和等矩形投影，生成透明背景的轻量 WebP 纹理。
- 运行时不加载 GeoJSON，不进行陆地判定，也不逐帧绘制圆点。
- 背景轨道使用可水平重复的纹理，通过 `transform: translate3d(...)` 匀速移动一个完整地图周期后复位，确保首尾无缝。
- 目标速度与参考实现一致，为约 `30px/s`。

未采用的方案：

- 直接移植 Canvas + GeoJSON：还原直接，但增加约 965 KB 静态资源和持续 CPU 开销。
- 内联 SVG 点阵地图：可缩放，但点位数量会显著增加源码体积和维护成本。

## 组件边界

### WorldMapBackground

新增独立装饰组件，职责仅包括：

- 渲染深色底色和循环点阵地图。
- 保持背景层 `pointer-events: none`，不影响表单交互。
- 使用 `aria-hidden="true"`，不向辅助技术暴露无意义内容。
- 响应 `prefers-reduced-motion: reduce`，保留静态地图并停止动画。

组件不读取认证状态、主题状态或公共设置。

### AuthLayout

增加显式布尔开关控制地图背景。默认值为关闭，避免改变其他认证流程。

启用时：

- 最外层背景固定为 `#0a0a12`。
- 地图位于内容下方，认证内容保持现有层级和最大宽度。
- 品牌标题、副标题、页脚使用适合深色背景的文字颜色。
- 表单卡片继续遵循现有主题样式，不改变字段和按钮设计。

### LoginView 与 RegisterView

仅在这两个页面调用 `AuthLayout` 时开启背景开关，不复制地图实现。

## 响应式与动画

- 地图使用固定逻辑尺寸，桌面和移动端通过裁切展示，避免按视口宽度缩放圆点。
- 动画层宽度覆盖“当前视口 + 一个完整地图周期”，移动过程中不会出现空白区域。
- 页面内容高度超过视口时，背景固定覆盖整个认证布局，滚动内容不暴露白底。
- 地图保持低对比度，表单卡片位于其上方，确保输入和按钮可读。

## 测试与验收

自动化测试：

- `AuthLayout` 默认不渲染地图背景。
- 开启属性后渲染地图组件和深色背景状态。
- `LoginView`、`RegisterView` 开启该属性，其他认证页面不受影响。
- 组件包含减少动态效果的静态降级规则。

工程验证：

- 运行相关 Vitest 测试、前端类型检查和生产构建。
- 在桌面与移动视口检查登录页和注册页。
- 验证地图持续循环、首尾无空白接缝、背景不拦截交互、内容无重叠。
- 验证亮色和深色主题下背景都保持深色，表单内容可读。

## 非目标

- 不把地图扩展到 Dashboard 或其他公开页面。
- 不新增地图交互、地点标注或主题色配置。
- 不修改运行态容器、数据库、Redis、Nginx 或公网链路。
