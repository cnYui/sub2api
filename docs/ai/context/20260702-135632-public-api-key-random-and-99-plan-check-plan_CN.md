# 公网随机用户与 99 元用户 API Key 真实请求检查计划

- 时间：2026-07-02 13:56 JST
- 目标：确认公网重启后，随机普通用户 API Key 能否真实请求公网 API；重点确认 99 元套餐用户是否已通过 79/99 新套餐链路公网打通。

## 步骤

1. 只读检查当前运行容器与公网健康状态，确认请求走公网入口。
2. 从公网 PostgreSQL 中只读查询：
   - 随机挑选若干 active API Key 所属用户；
   - 定位当前 99 元套餐对应的 active subscription 用户与 API Key。
3. 使用每个样本的 Key 对 `https://api.aaccx.pw/v1/responses` 发真实小请求。
4. 记录每次响应 HTTP 状态、错误码或请求成功信号；不记录完整 API Key。
5. 若 99 元用户仍失败，再按日志和数据库链路定位失败层。

## 安全约束

- 不输出完整 API Key。
- 不写入数据库。
- 不改容器、镜像、nginx 或运行态配置。
