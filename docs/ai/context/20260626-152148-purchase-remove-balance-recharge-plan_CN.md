# /purchase 下架余额充值页面计划

## 目标

- `/purchase` 只保留订阅套餐和 GPT 流量包购买。
- 不再展示“充值”tab、充值账户、快捷金额、自定义金额和余额充值支付按钮。
- 即使 URL 带 `?tab=recharge`，页面也回到订阅购买视图。

## 边界

- 本次只下架前端用户购买页的余额充值入口。
- 不删除后端余额订单 API、历史订单、后台配置和支付 provider 能力，避免影响旧数据与后台运维。
- 订阅与流量包仍通过现有 ZPay/EasyPay 支付和 1% 手续费展示链路。

## 实现

1. 在 `PaymentView.spec.ts` 增加回归测试：
   - 默认 `/purchase` 不渲染 tab 切换与充值账户。
   - `?tab=recharge` 仍显示订阅卡，不显示充值金额 UI。
2. 修改 `PaymentView.vue`：
   - `tabs` 固定只保留订阅，tab 切换隐藏。
   - `activeTab` 固定订阅，不再允许 route query 切到 recharge。
   - 保留与订阅/流量包相关的支付状态和支付方式逻辑。
3. 跑前端相关测试与类型检查。

## 风险

- 如果未来仍需要余额充值，可通过恢复 UI 分支或新增独立路由重启，不影响后端能力。
