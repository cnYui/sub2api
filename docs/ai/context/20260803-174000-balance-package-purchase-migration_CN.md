# 余额套餐购买页迁移记录

## 背景

此前 `/purchase` 同时展示普通余额充值和绑定模型分组的订阅卡。模型分组订阅会把 `group_id` 写进订单并影响订阅关系，不符合“用户购买人民币额度、自由调用七种渠道”的业务定义。

## 决策

- 新增 `balance_package_plans` 保存人民币价格和美元周额度。
- 新增 `user_balance_packages` 保存支付后的到账快照和周期状态。
- 余额套餐订单使用 `order_type=balance_subscription`，只保存余额套餐快照，不写模型订阅分组。
- 支付成功立即到账一次，之后每 7 天到账一次，共 4 次，周期到账使用条件更新和唯一订单号保证幂等。
- `/purchase` 只渲染 `balance_packages`，每张卡展示人民币价格、每周美元余额、28 天、4 次到账和总到账额度；流量卡与模型订阅不再混入该页面。
