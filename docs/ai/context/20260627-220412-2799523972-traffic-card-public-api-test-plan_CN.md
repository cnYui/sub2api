# 2799523972@qq.com 流量卡公网 API 实测计划

时间：2026-06-27 22:04 JST

## 目标

使用 `2799523972@qq.com` 名下现有 API Key 通过公网 `https://api.aaccx.pw` 发起一次真实模型请求，验证在订阅已取消、账户仅剩流量卡时，请求是否能通过并真实消耗流量卡余额。

## 约束

- 不打印、不记录完整 API Key。
- 不修改用户套餐、流量卡、余额、API Key 或支付配置。
- 请求尽量小，降低真实扣费成本。
- 只读查询数据库前后快照，除真实 API 请求产生的正常计费写入外，不做手工写入。

## 步骤

1. 查询用户 ID、API Key 状态、订阅状态、流量卡状态和相关账单表结构。
2. 记录请求前的流量卡余额、已用量、相关用量/账单记录计数。
3. 从数据库读取该用户可用 API Key 到 shell 变量，不输出明文。
4. 对公网 `https://api.aaccx.pw/v1/chat/completions` 发起最小真实模型请求。
5. 记录 HTTP 状态、响应中的模型/usage/短内容，不输出 Key。
6. 再次查询流量卡余额、已用量、账单/请求记录变化。
7. 写入实测结果文档并汇报结论。

## 判断标准

- 如果请求返回 200，且请求后流量卡 `remaining_amount` 或等价余额字段下降、`used_amount` 或等价字段上升，则证明流量卡已真实兜底扣费。
- 如果请求被拒绝，则根据错误码判断是否仍被订阅额度准入拦截。
- 如果请求成功但流量卡无变化，则继续追查账单记录是否异步延迟或扣到了其他余额来源。
