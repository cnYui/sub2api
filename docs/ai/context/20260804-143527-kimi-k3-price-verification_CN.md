# Kimi K3 单条价格复核

## 浏览器记录

在 `api.ai-genesis.app/usage` 的 API Key `k3` 明细中，截图对应记录为：

- 模型：`kimi-k3`
- 输入 token：`135`
- 输出 token：`33`
- 输入单价：`$3 / 1M Token`
- 输出单价：`$15 / 1M Token`
- 中转倍率：`3.5x`
- 页面用户扣费：`$0.003150`

## 复算

```text
输入费用 = 135 × 3 / 1,000,000 = 0.000405
输出费用 = 33 × 15 / 1,000,000 = 0.000495
标准成本 = 0.000405 + 0.000495 = 0.000900
中转站实际费用 = 0.000900 × 3.5 = 0.003150
```

结论：本地在最终 `15x` 之前的 Kimi K3 费用与别人中转站的 `$0.003150` 完全相同；本地余额最终扣费为 `0.003150 × 15 = $0.047250`。
