# 退款按余额套餐实际承担比例修复

## 结论

退款报价不再汇总周期内全部 `usage_logs.actual_cost`。流量卡、普通余额和流量卡欠费均不参与余额套餐退款比例；只有实际从余额套餐 `remaining_usd` 扣除的金额才计入。

## 实现

- 新增迁移 `211_balance_package_usage_ledger.sql`，建立不可变的余额套餐消费账本和幂等唯一约束。
- 普通请求在余额扣减事务中写入实际套餐扣款金额。
- 批量图片在最终 capture 事务中写入实际套餐承担金额，hold 释放和未使用部分不会计入。
- 退款报价按账本聚合；历史套餐由迁移写入 `legacy_unattributed` 标记，报价转人工审核，不继续使用无法区分资金来源的全量用量。
