# 新手引导弹窗视觉统一计划

## 目标

将 Driver.js 新手引导弹窗调整为与后台一致的黑白灰视觉体系，统一系统字体、按钮、边框、阴影和深色模式，并移除引导文案中的彩色 emoji。

## 范围与取舍

- 保留现有引导步骤、交互和国际化文案内容，不改业务流程。
- 在步骤交给 Driver.js 前统一清理标题、说明和按钮文字中的 emoji，避免分别维护中英文文案。
- 仅覆盖 `theme-tour-popover` 及 Driver.js 高亮样式，不影响普通弹窗。
- 采用现有页面的灰阶、圆角和系统字体；主按钮使用黑白反色，深色模式对应反色。

## 实施顺序

1. 添加失败测试，锁定 emoji 清理和引导样式不使用蓝绿配色。
2. 提取纯函数处理 Driver.js 步骤文案，并在引导启动时调用。
3. 重写引导 CSS 的亮色、深色、按钮、快捷键和高亮样式。
4. 运行定向测试、类型检查和构建；重启本地开发容器供人工查看。
