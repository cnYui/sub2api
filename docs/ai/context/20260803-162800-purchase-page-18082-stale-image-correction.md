# 18082 旧购买页镜像修正记录

时间：2026-08-03 16:28:00（Asia/Tokyo）

## 问题原因

首次重启使用了 `--no-build`，但此前异步 Docker 构建尚未完成。应用容器因此绑定了旧镜像；随后构建完成才更新同名镜像标签，已运行的容器不会自动切换到新镜像。

## 修正

在镜像构建完成后再次使用 `--force-recreate` 仅重建 `sub2api` 应用容器，PostgreSQL、Redis 及其数据卷保持不变。

## 验证

- 当前容器：`running healthy`
- 当前镜像包含新购买页代码（已检查嵌入式前端资源）
- `GET http://127.0.0.1:18082/purchase`：HTTP 200
- 旧镜像 ID 与悬空镜像均已不存在

浏览器若仍显示重启前页面，需要刷新当前页面以丢弃已加载的旧 JavaScript。
