# 18080 前端主题与品牌复刻

## 背景

本地 `main` 分支的前端需要仅调整视觉主题与默认品牌，参考 `http://127.0.0.1:18080`。不修改后端接口、设置数据、支付逻辑或页面业务结构。

## 参考值

- 深色页面背景：`#09090b`
- 深色面板：`#18181b`
- 深色边框：`#27272a`、`#3f3f46`
- 主色：`#3b82f6`
- 字体资源：Playfair Display 与 Inter；页面字体栈保持参考站点的系统无衬线回退顺序
- 图标：参考站点的 `/logo.png`，256 x 256 PNG

## 决策

- 通过 `tailwind.config.js` 统一替换主色和深色层级，确保既有 `dark:*` 类无需逐页重写。
- 保留现有路由、组件结构和运行时站点设置覆盖机制；仅将静态及网络失败时的默认站名改为“天才程序员小站”。
- 将无后台 Logo 配置时的展示与 favicon 统一回退到新增的 `frontend/public/logo.png`。
