# 961109198 Chat Completions 流式 502 根治实现结果

## 结论

已在本地分支 `codex/fix-chat-completions-raw-routing` 完成代码根治：OpenAI APIKey 账号在自动模式下收到标准 `/v1/chat/completions` body（存在 `messages`）时，优先 raw 直转上游 `/v1/chat/completions`，不再因为账号探测支持 Responses 就默认走 Chat Completions 到 Responses 转换。

这能避开 `961109198@qq.com` 所遇到的 `/v1/chat/completions` 流式请求在 CC→Responses 路径中缺 terminal usage 后返回 502 的问题，同时保留账务保护：raw chat 流式路径仍强制 `stream_options.include_usage=true`，若上游仍不给 usage，不会伪装成功。

## 行为变化

- APIKey + `auto` + Chat shape（有 `messages`）：走 raw `/v1/chat/completions`。
- APIKey + `auto` + Responses shape（无 `messages`、有 `input`）：保留现有 `/v1/responses` 兼容路径。
- APIKey + `force_chat_completions`：继续强制 raw chat。
- APIKey + `force_responses`：继续强制 CC→Responses。
- OAuth/ChatGPT 账号：继续走原有 CC→Responses 路径。
